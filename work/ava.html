ASBL

AVA · Conversational AI Assistant

Chat accuracy from 72% to 91%

The assistant sounded fluent and still missed. Fluency is not a metric. A 300-question test set is.

Role: RAG + evaluation Stack: LLMs, retrieval, prompt engineering, eval set

  • 200+ curated documents
  • 300 evaluation questions
  • 72→91% answer accuracy

Problem

Buyers asked project, payment, and possession questions in chat. The first RAG build retrieved something and answered anyway. Demoed well. Failed the questions that mattered: pricing rules, possession dates, documents that contradicted each other.

Approach

I curated 200+ source documents and wrote a 300-question evaluation set that mirrored real chats, not brochure copy. Each miss pointed at a gap: missing chunk, stale fact, or a prompt that let the model guess. Fix the knowledge base, re-run the set, keep only the lifts that hold.

Result

Accuracy moved from 72% to 91% on the same test. The useful part was not the model swap. It was treating the chatbot like any other model: a holdout, a miss list, and a patch.
